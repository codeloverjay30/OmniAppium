# 說明
針對<<胸懷三國-美人計>>這個手遊

大部分活動(有些達成後有獎勵可以領)頁面在主頁面(如下圖所示)的右上角區塊中的圖示可以被找到。

在每個圖示的右上角可能會有紅色小圓點(代表有通知)。

根據我的觀察，在圖示的右上角會有紅色小圓點會顯示，只有當該內部跳轉的頁面含一個或多個Entries(包含Tab)，其右上角有點點(代表有通知)。

根據我的觀察，在Tab的右上角會有紅色小圓點會顯示，只有當該Tab內部的頁面含一個或多個項目，其右上角有點點(代表有通知)。

根據我的觀察，在Leaf項目(且沒有子項目)的右上角會有紅色小圓點會顯示，只有當我在這次登入時還沒點擊該Leaf項目圖示。

舉例:

+ 在下圖，胸懷三國美人計--超值活動--黃天當立Tab的右上角有紅色小點點，因為(在該Tab)兌換商店的圖示中有上角含有紅色點點(代表我在這次登入還沒點擊過`兌換商店`Leaf項目圖示)。

+ 在下圖，我們可以在胸懷三國美人計的主頁面中看到`超值活動`這個圖示的右上角還有紅色圓點，因為該頁面內部的`黃天當立`這個Tab的右上角有紅色點點(如下圖所示)
